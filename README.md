# Таптар — учёт рейсов и расходов для водителей-перевозчиков

Android-приложение для индивидуальных предпринимателей, работающих на собственном грузовом транспорте.

## Возможности

**Рейсы (доход):**
- Номер рейса, дата, зона по дальности (от 3 до 6 зон, диапазоны настраиваются)
- Стоимость рейса рассчитывается автоматически по цене зоны
- Отметка «был возврат» — +50% к оплате рейса
- Количество точек выгрузки (до 25) — оплата настраивается (со скольких точек и сколько за точку)
- Заметка к каждому рейсу

**Расходы:**
- Учёт по категориям: топливо, платные дороги, ремонт, запчасти, шины, ТО, страховка, налоги, штрафы, связь, питание, проживание, прочее

**Аналитика:**
- Сводка за текущий месяц: доход, расход, прибыль
- Статистика за любой месяц или произвольный период
- Расходы по категориям с диаграммами

**Прочее:**
- Экспорт всех данных в CSV (для Excel)
- Все данные хранятся локально в SQLite на устройстве
- Работает без интернета, не запрашивает разрешений

## Требования

- Android 5.0 (API 21) и выше
- Android SDK (platform android-34, build-tools 34.0.0) для сборки
- JDK 8+ для компиляции

## Сборка

```bash
./build.sh
```

Скрипт компилирует исходники (`javac` → `d8`), собирает и подписывает APK. Результат: `build/Таптар.apk`.

Сборка AAB (для публикации) выполняется через `bundletool` из proto-ресурсов, собранных `aapt2` (см. историю сборки в репозитории).

## Структура проекта

```
AndroidManifest.xml       — манифест приложения
build.sh                  — скрипт сборки APK
res/                      — ресурсы (иконка)
src/ru/trucker/money/
  MainActivity.java       — главный экран: сводка за месяц, последние записи
  AddActivity.java        — форма рейса / расхода
  HistoryActivity.java    — история, фильтры, удаление
  StatsActivity.java      — статистика по периоду, диаграммы
  SettingsActivity.java   — настройки зон и точек выгрузки
  DbHelper.java           — SQLite (рейсы, расходы)
  Zones.java              — логика зон, цен, точек выгрузки
  RecordsAdapter.java     — адаптер списка записей
  Util.java               — вспомогательные функции
```

## Подпись

Приложение подписывается локальным ключом `key.jks` (алиас `trucker`). **Ключ не загружен в этот репозиторий** — храни его в надёжном месте: без него нельзя будет выпускать обновления с той же подписью.

Для публикации в RuStore используется схема pepk: архив с зашифрованным ключом (`pepk_out.zip`) загружается в консоль разработчика, Рустор подписывает AAB этим же ключом.
